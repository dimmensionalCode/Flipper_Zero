Le Flipper Zero est un dispositif portable multifonction conçu pour interagir avec divers systèmes de contrôle d'accès et appareils électroniques. Il est capable de lire, copier et émuler des étiquettes RFID et NFC, des télécommandes radio, des iButtons, divers types de clés d'accès numériques et dispose également d'une interface GPIO. L'appareil se compose d'un petit boitier sur lequel se trouve un pavé directionnel, deux boutons et un écran monochrome de 1,4 pouce. L'interface utilisateur de l'appareil prend pour modèle un dauphin virtuel
